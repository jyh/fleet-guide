# fleet-guide

A field guide to running a fleet of long-running AI agent sessions ("seats"): the roles, the shared files, the bus, gates and the keeper, a seat's boot-work-bank cycle, the duty officer, the daily council, verification habits, and the practical operation on one machine (tmux, loops, keystrokes, hazards).

It is written to be handed to an agent that has nothing but this text. It names no particular account, machine or project, and it ships no code: every mechanism is described well enough to rebuild.

- The guide: [FLEET-GUIDE.md](FLEET-GUIDE.md)
- Raw, for an agent to fetch: `https://raw.githubusercontent.com/jyh/fleet-guide/main/FLEET-GUIDE.md`
